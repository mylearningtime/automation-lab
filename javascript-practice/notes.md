# JavaScript Basics Notes

## What is a variable?

A variable is a named container used to store data that can be referenced and used later in a program.

## Difference between const and let

const creates a variable that cannot be reassigned to a different value.

let creates a variable that can be reassigned later. e.g. name, dob etc.
let assigns temperor value to a variable e.g. balance = $200

## What does console.log() do?

console.log() prints information to the console or terminal.
